Installation

Gmail : Paramètres → Voir tous les paramètres → Signature → Créer → coller (Ctrl+V).
Outlook Web / New Outlook : Paramètres → Comptes → Signatures → coller.
Outlook classique (Windows) : Fichier → Options → Courrier → Signatures → coller.
Apple Mail : Réglages → Signatures → coller (décocher « Toujours utiliser ma police par défaut »).
Champs vides : les lignes téléphone, mobile, adresse, horaires et le bouton LinkedIn disparaissent automatiquement.
